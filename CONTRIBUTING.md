# Contributing

Welcome—thanks for contributing!

Quickstart:
- Python 3.10+ recommended
- Create venv: `python3 -m venv .venv && source .venv/bin/activate`
- Install: `pip install -r requirements.txt`
- Run tests: `pytest`
- Run example: `python akshay-llm-roadmap/examples/experiment.py`

Creating issues:
- Use the JIRA board for sprints and stories
- Follow the 4-subtask structure (Work / Side / Smol / Learning)

Code style:
- Run `flake8` and follow simple linter feedback

Thanks!
